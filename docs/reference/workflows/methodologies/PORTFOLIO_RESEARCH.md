# Portfolio Research — methodology

Return to the [methodology chooser](../RESEARCH_METHODOLOGIES.md). This page explains the research question and evaluation method; the workflow reference owns contracts and persisted outputs.

## 9. Portfolio Research

Portfolio Research is a planned methodology.

### Research Question

> How should multiple strategies be combined, allocated and evaluated as a portfolio?

### Planned Scope

- correlation between strategies,
- capital allocation,
- portfolio drawdown,
- risk contribution,
- diversification,
- turnover,
- capacity,
- portfolio robustness,
- execution constraints,
- strategy replacement and deactivation rules.

### Planned Workflow

```text
Persisted Strategy Results
  → Temporal Alignment
  → Portfolio Composition
  → Allocation Rules
  → Portfolio Simulation
  → Portfolio Analytics
```

### Expected Outputs

- portfolio equity curve,
- strategy contribution,
- risk contribution,
- allocation history,
- portfolio drawdown,
- diversification metrics,
- portfolio-level robustness diagnostics.
